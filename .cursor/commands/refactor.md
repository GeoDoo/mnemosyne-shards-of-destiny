When I ask you to "refactor" or use this rule:
1. **Analyze**: Identify code smells (nested loops, long methods, magic numbers).
2. **KISS & DRY**: Simplify logic and remove redundancy.
3. **Type Safety**: Ensure all variables have strict types (if using TS/Python).
4. **Performance**: Optimize time/space complexity without losing readability.
5. **No Regression**: Check existing tests to ensure behavior is preserved.
