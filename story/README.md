# Story Bible

This folder contains the narrative content for **Mnemosyne: Shards of Destiny**.

## Structure

```
story/
├── README.md              # This file
├── 00_intro.md            # Opening narration and key story elements
├── 01_chapter1_awakening.md   # Chapter 1: The Awakening
├── 02_chapter2_*.md       # Chapter 2 (future)
├── characters/            # Character backgrounds and arcs
├── lore/                  # World-building, mythology, Orphic mysteries
└── dialogues/             # NPC dialogue scripts
```

## Naming Convention

- `00_` — Introduction, world setup
- `01_`, `02_`, etc. — Chapters in order
- Use descriptive suffixes: `_awakening`, `_descent`, `_revelation`

## Writing Guidelines

1. **Vision sequences** use auto-continue (`true`) for cinematic flow
2. **NPC dialogue** uses manual continue (player presses to advance)
3. Mark dialogue with speaker name or `*narration*` for internal thoughts
4. Keep individual dialogue lines short (fit on screen)

## Key Terms

- **Mnemosyne**: Titan goddess of Memory, mother of the Muses
- **Shards of Destiny**: Fragments of divine memory scattered across the world
- **Red Moon**: Celestial event tied to the Orphic prophecy
- **Orphics**: Secret religious movement with hidden knowledge
- **Memory Flash**: Alexios's signature ability, channeling divine memory
